Funding sources library

Known custodial hot wallets (exchanges) that fund personal wallets. These ship with the extension and label matching addresses everywhere they appear. Add your own — saved to this install and applied immediately.

    Not-a-side-wallet flags

    Transfers you marked as “not a side wallet”. These are scoped to the specific wallet you were analyzing — the same address can still be flagged as a suspect when you analyze a different wallet.

      Connector wallets

      Relayer/connector wallets (Phantom, Fomo, etc.) you marked. They're never removed or hidden — they simply stop being highlighted as suspects in every analysis.

        Ansem wallets

        Known Ansem wallets. When ≥45% of a token's supply moves between an analyzed wallet and one of these, the lead is tagged “Ansem Derived Coin Supply Share” and its certainty is damped — these distributions are a recognised source of supply-sharing false positives. None ship built-in; add addresses you've verified, or use “◎ Ansem wallet” directly on a result.

          Flagged as incorrect

          Results you flagged as wrong. ARRAY.FIND keeps the evidence behind each one so you can review what triggered the false positive, and export the set to help improve accuracy.

            Updates

            Installed version –
            Install folder Not linked yet

            One-time setup: “Link install folder” — point at the exact folder shown as this extension’s Path in chrome://extensions (grant write). Then “Update from folder” copies a newer version into it, verifies the files landed, and reloads. If verification fails it won’t reload and tells you the folder was wrong. “Reload now” just re-reads the current folder. The extension is identified by its files, so renaming it between versions no longer breaks updates.

            ⚠ Analyzing more than 10,000 transactions can take a while and use more API credits. Max 50,000.

            These apply per analysis and naturally differ between wallets — tune them here before analyzing. Higher transaction counts dig deeper but cost more time and API credits.

            To update any wallet with new search settings, simply change the filters above, then select the wallet — it re-analyzes with those parameters.

                                  Constellation
                                  Strongest connections sit closest · line colour = flow (green in · purple out · teal two-way), arrowed · pink line = between other wallets · thicker line = more transfers
                                  1×

                                  Hover or tap a node for details. The large node is the tracked wallet — placed in a spot unique to that wallet, which drives the whole arrangement. The strongest leads (≥30%) sit out toward the edges where they have room; weaker links fill the space between, and long connections may bend at an angle to use free space. Each line is coloured and arrowed by flow direction — inflow, outflow or two-way, per the legend above — and gets thicker the more transfers there were. The separately-coloured solid lines mark interactions between the other wallets, arrowed the same way (both ways when they went both ways). Pick a colour palette from the dropdown — recolouring never moves anything. Type a % to hide weaker connections without moving anything — “Show/Hide infrastructure” likewise only adds or removes the grey clusters, nothing else moves. Press Reset to restore the original layout. “Select group” moves several nodes at once — click or drag-select to add nodes, drag any selected node to move the whole group, click empty space to clear and start another selection, Enter to finish. Scroll to zoom (or use −/+); when zoomed, drag the background to pan. Labels show your names where set, otherwise the short address.
